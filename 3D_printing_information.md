#### Overview
Here are the different parts that are important in this build. I've included screenshots for each part for how I printed it (I also think that is the best printing orientation, so if you are new to 3D printing, that's how you should do it) 

Everything is printed in White PLA on an Ender 3 V2. I am using the default settings on PrusaSlicer. 

##### Angler - 8.96 grams of filament
These can be customized to change how far off the ground you want the macropad to stand. Currently, it is at about 8 degrees. They are super interchageable (4 screws hold them in place, so they are not permanently attached)

**ANGLER IMAGE** 

##### Top Plate - 23.04 grams 
This is where everything is plopped into. Note that you have to put lots of heat set inserts in for this piece. Make sure you see some video tutorials on how they work first so you don't have to reprint. For the key switches, I choose 14.0 mm (which is standard for switches), and they were able to fit well. If your switches are different, you may need to download the onshape file and change it (it can't accomodate too large of a change, so if you have a very unconventional switch, it will probably not render properly) 

**TOP PLATE IMAGE** 

##### Bottom Plate - 63.38 grams 
This is where the raspberry pi is screwed into, you may need to cut off some of the port to get the raspberry pi port to fit through. You have to put heat set inserts in the bottom for the anglers to screw into. 

**BOTTOM PLATE IMAGE**

##### Test Plate - 0.64 grams
THis is used to test the different sizes of the switches that your printer creates so you know what size hole you need for the switches.
